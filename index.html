Iris Media Manager プライバシーポリシー

制定日：2026年10月27日

Iris Media Manager（以下「本アプリ」）は、炭素回収技術研究機構株式会社（以下「CRRA」）が、村木風海の Instagram アカウント（@kazumi_muraki.official）の運用のために使う、社内専用のアプリです。一般の方に提供するサービスではありません。

1. 取り扱う情報

本アプリは、Meta が提供する Instagram API を通じて、上記アカウントについて次の情報を取り扱います。

  • アカウントのプロフィール情報と、投稿した写真・動画・キャプション
  • 投稿やアカウントの統計情報（表示回数・リーチ・いいね数などのインサイト）
  • 上記アカウントの投稿に寄せられたコメント、および上記アカウントに届いたメッセージ

2. 利用目的

取得した情報は、上記アカウントへの投稿、統計の分析、コメントの管理（返信・非表示など）、メッセージへの対応のためだけに使います。

3. 第三者への提供

法令に基づく場合を除き、取得した情報を第三者に提供・販売することはありません。

4. 保管と管理

情報は CRRA が管理する機器に保存し、目的に必要な期間を過ぎたものは削除します。

5. データの削除のご依頼・お問い合わせ

ご自身のコメントやメッセージに関する情報の削除をご希望の方、そのほか本ポリシーに関するお問い合わせは、下記までご連絡ください。
